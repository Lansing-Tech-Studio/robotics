# Lansing Tech Studio Robotics Hub

The landing page at <https://lansingtechstudio.org/robotics> that points visitors
at each team's blog. Published by GitHub Pages from `main`.

Teams used to publish their blogs, notes, and programs into this repo. They now
run their own sites, so this repo holds nothing but the front page and the list
of teams.

## Adding a team, or linking one up

Everything on the front page is generated from [`_data/teams.yml`](_data/teams.yml).
Add an entry, or fill in the `site:` field once a team's blog exists:

```yaml
- name: Team 5
  slug: team5
  program: fll
  season: 2026
  status: active
  coach: Coach Name
  logo: /team-logos/team5.png
  site: https://lts-team5.github.io/
```

A team with no `site:` shows "Blog coming soon" instead of a link. Set
`status:` to anything other than `active` to drop a team off the page.

## Team colors and shapes

Each team has a color **and** a shape. Reuse both, together, on anything that
identifies a team — name tags, bins, table signs, robot cases, jerseys.

| Team   | Hex       | Shape    |
|--------|-----------|----------|
| Orange | `#e8590c` | triangle |
| Red    | `#c92a2a` | circle   |
| Green  | `#2f9e44` | square   |
| Blue   | `#1971c2` | diamond  |
| Yellow | `#eab308` | star     |

The shape is not decoration. Simulated against red-green color blindness these
five colors collapse into two indistinguishable pairs — orange and yellow both
read olive, red and green both read khaki — leaving only blue distinct. So a
kid who can't tell the pairs apart is reading the shape, which means anything
that uses the color alone excludes them.

The shapes are drawn into the robot artwork in
[`assets/images/`](assets/images/) (`robot-<color>.png`). Note the vivid hex
above is a fill and border color; it fails contrast as text on white, so darken
it for type — `roster.html` uses `color-mix(in srgb, var(--team) 55%, #111)`.

## Adding a page to the menu

The sidebar comes from `navigation:` in [`_config.yml`](_config.yml). Any entry
can carry a `subnav:`, and a `subnav:` entry can group links under a heading by
using `items:` instead of a `url:` — same shape as the workshops site.

Team logos are generated by the little tool in [`team-logos/`](team-logos/) —
open `render.html` in a browser.

## Where everything else went

- **Team blogs** — each team's own repo, created from
  [team-blog-template](https://github.com/Lansing-Tech-Studio/team-blog-template).
- **Layouts and styling** — shared with the team sites via `remote_theme`, in
  [lts-team-blog-theme](https://github.com/Lansing-Tech-Studio/lts-team-blog-theme).
  The only local exceptions are the sidebar menu's `_layouts/default.html`,
  `_includes/nav.html`, and `assets/style/nav.css`, ported from the workshops
  site. Everything else — colors, type, the team card grid — still comes from
  the theme, so put styling changes there.
- **Old team posts, programs, and the printable meeting templates** —
  [`_archive/`](_archive/README.md), pending handoff to the teams. Delete that
  folder once they've taken their content back.
